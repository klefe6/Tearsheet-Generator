# Tearsheets

A collection of Python scripts and tools for generating trading strategy tearsheets and financial analysis reports.

## Contents

- **tkp_ts.py** - Main tearsheet generator using Dash and Plotly
- **Gold_Maker_ts.py** - Gold strategy tearsheet generator
- **tsgen.py** - General tearsheet generation utility
- **tv_vadi_convert.py** - TradingView VADI converter
- **spx_data_test.py** - S&P 500 data testing script
- **requirements.txt** - Python dependencies
- **assets/** - CSS styling and assets

## Setup

1. Install Python dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the main tearsheet generator:
   ```
   python tkp_ts.py
   ```

## Features

- Interactive web-based tearsheets using Dash
- Financial data visualization with Plotly
- Performance metrics and analysis
- Customizable styling and layouts
